# Mobile brand assets

Official Auvora Professional Brand Kit copies for Flutter.

- Prefer `Auvora_Primary.png` on light surfaces
- Prefer `Auvora_Reverse.png` on dark / splash
- Prefer `Auvora_Symbol.png` for compact marks
- App icon master: `Auvora_App_Icon.png` (also used for Android adaptive foreground)

Do not use `Auvora_Brand_Preview.png` as in-app artwork.
