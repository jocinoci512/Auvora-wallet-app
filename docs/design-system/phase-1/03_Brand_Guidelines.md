# 03 — Brand Guidelines

**Brand:** Auvora  
**Design language:** Aether  
**Positioning line:** _The quiet operating system for digital value._

---

## Brand essence

Auvora is **composed wealth technology**.  
It should feel like opening a private banking app designed in 2030 — not a DeFi carnival, not a spreadsheet, not a clone of any popular wallet.

**Essence word:** _Clarity._  
**Supporting words:** Precise · Calm · Credible · Modern · Human.

## Logo & wordmark

### Principles

- Wordmark-first (typography is the brand)
- Optional mark: a minimal **orbit notch** — a single open arc suggesting continuity and custody, never a cartoon coin
- Clear space: ≥ height of the capital “A” on all sides
- Never place the mark on busy photography or neon gradients

### Lockups

1. **Primary:** Syne wordmark, weight 700, tracking slight negative
2. **App icon:** Lagoon field + monoline orbit on mineral light or ink
3. **Monochrome:** Ink on canvas, or canvas on ink

### Don’ts

- No metallic chrome bevels
- No purple glow, crypto-laser strokes, or 3D coins
- No stretched or outlined wordmarks
- No emoji in the official lockup

## Color personality (summary)

Full tokens: `04_Color_System.md`.

- **Canvas:** Cool mineral light (`Mist`) — not warm café cream, not pure stark white
- **Ink:** Deep blue-charcoal (`Obsidian`)
- **Signal:** Deep lagoon (`Lagoon`) — primary interactive color, used sparingly
- **Lumen:** Soft aqua highlight for focus / live only
- **Reserve:** Muted gold (`Reserve`) for verified / premium moments only

Dark mode is a first-class twin, not an afterthought invert — still mineral, never purple-black.

## Voice & tone

### Voice attributes

1. **Direct** — short verbs
2. **Calm** — never shout
3. **Specific** — amounts, networks, fees named
4. **Respectful** — no condescension to beginners; no jargon flex to pros

### Examples

| Context      | Write                                        | Avoid                                  |
| ------------ | -------------------------------------------- | -------------------------------------- |
| Send confirm | “Send 0.42 ETH to Alex. Network fee ~$1.20.” | “Are you SURE you want to broadcast!?” |
| Error        | “We couldn’t reach the network. Try again.”  | “RPC_ERROR_TIMEOUT”                    |
| Empty NFTs   | “No collectibles in this wallet yet.”        | “Your gallery is sad 😢”               |
| Success      | “Sent. It’s on the way.”                     | “WAGMI!!”                              |

---

## Imagery & illustration

- **Product photography:** real devices, soft daylight, no neon desk setups
- **Illustration:** line-forward, geometric, 1–2 colors max (Lagoon + Ink). No isometric crypto cities
- **Empty states:** one quiet illustration + one sentence + one CTA
- **Charts:** flat, thin strokes, no gradient fills unless data requires area emphasis — then 8–12% opacity max

---

## Iconography

- Style: **2px stroke**, rounded joins, optical square 24×24, live area 20×20
- Corner radius in glyphs: match Aether radius `sm` feel
- Prefer lucide-compatible geometry for engineering velocity; custom set must match stroke
- Filled icons only for selected nav / critical status
- Never mix filled decorative icons with stroke UI icons in one toolbar

---
