# 03 — Customer Experience

## Goal

Every touchpoint should **reduce anxiety** and make control obvious: what is happening, why, and what the user controls.

## Touchpoint review

| Touchpoint                                | State                                      | Anxiety posture                  |
| ----------------------------------------- | ------------------------------------------ | -------------------------------- |
| Onboarding / create / import / restore    | Wizard shells + recovery guidance          | Strong; never ask phrase in chat |
| Send / Buy / Sell / Swap / Bridge / Stake | Honesty banners; preview ≠ success         | Strong (Phase 9)                 |
| Security Center                           | Score + recommendations                    | Educates without panic           |
| Notifications / prefs                     | Local prefs; smart alerts privacy-aware    | Keep non-spammy                  |
| Emails                                    | Not production-templated                   | Block GA until ESP + templates   |
| Security alerts                           | Product patterns exist; channel incomplete | Need real delivery               |
| Help / FAQ                                | In-app FAQ + legal/trust/status            | Placeholder contacts labeled     |
| Feedback                                  | Mailto / issue placeholders                | Honest labels OK for beta        |
| Product tours                             | Light; avoid modal spam                    | Prefer progressive disclosure    |
| Errors / offline / 404                    | Calm copy                                  | Strong after Phase 10            |
| Incidents                                 | `/status` + Trust page principles          | Align with ops runbooks          |

## Support principles (company)

1. Support **never** asks for recovery phrases.
2. Status first — check `/status` before escalating fear.
3. Placeholder inboxes must stay labeled until replaced.
4. Demo admin Support stays demo-labeled (Phase 8).

## CX improvements this phase

- Discoverable Legal, Trust, Status from Help, Settings, Nav
- 404 with wallet / help / status escapes
- Offline: reassure keys stay on device

## Gate

**Customer experience: Pass** for preview/beta honesty; **Conditional** for public support channels until production contacts and email exist.
